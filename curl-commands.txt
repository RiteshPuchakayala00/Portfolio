# Backend Integration Test Commands

## B1: Health Check
curl -X GET http://localhost:5000/

## B2: GET All Projects
curl -X GET http://localhost:5000/api/projects

## B3: GET Single Project
# Valid ID
curl -X GET http://localhost:5000/api/projects/1

# Invalid ID (404)
curl -X GET http://localhost:5000/api/projects/999

## B4: POST Contact Submission
# Valid submission
curl -X POST http://localhost:5000/api/contact \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"Test User\",\"email\":\"test@example.com\",\"message\":\"Hello world!\"}"

# Invalid submission - missing email
curl -X POST http://localhost:5000/api/contact \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"Test User\",\"message\":\"Hello world!\"}"

# Invalid submission - invalid email
curl -X POST http://localhost:5000/api/contact \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"Test User\",\"email\":\"testexample.com\",\"message\":\"Hello world!\"}"

## B5: GET Submissions
curl -X GET http://localhost:5000/api/contact

## B6: Centralized Error Handling & 404s
# Undefined route
curl -X GET http://localhost:5000/api/doesnotexist
